# Aura Store - E-Commerce Flutter Application

A feature-rich e-commerce mobile application built with Flutter, designed to provide a seamless online shopping experience with clean architecture and modern UI.

---

## 🚀 Features

* **Modern User Interface:** Built using Flutter widgets for a smooth and responsive experience.
* **Product Catalog:** Browse products seamlessly with categorized views.
* **Cart & Checkout:** Manage selected items and proceed through a streamlined checkout flow.
* **State Management:** Efficient handling of app state for optimal performance.

---

## 📱 Tech Stack

* **Framework:** Flutter
* **Language:** Dart
* **Platform Support:** Android & iOS
